## Featured project
**[Circuit Simulator](https://github.com/PeterNegrut/CircuitSimulator)** · Python, NumPy, pytest
A circuit simulator built from scratch: parses JSON netlists, solves for node voltages and branch currents, and simulates capacitor and inductor transients with backward Euler implicit integration. Each solver stage is verified by a pytest suite; nonlinear component models are in progress.
